    Formula

    net(m)          = gain − carry     (gain = 0 for months 1 to delay)
cumulative(m)   = −setup + net(1) + … + net(m)
break-even      = first month where cumulative(m) ≥ 0
Fee path        : setup = gap × (1 + fee %)
Stake path      : setup = gap; after break-even the partner takes stake % of each month's net
Bad-case line   : bad-case break-even must land by the month you set
Safe gap        ≤ line × (gain × bad % − carry) ÷ (1 + fee %)

    Dollars round to whole dollars. Months round up to whole months. If gain does not cover carry, the page says No break-even.
