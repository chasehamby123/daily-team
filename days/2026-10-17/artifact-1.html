7. The formulas

r      = sum(billed x overturn %) / sum(billed), payer and code groups with a rate
C      = hire cost + tool cost, per month
Recovered per month   = D x r
Hire monthly net      = D x r - C
Vendor monthly net    = D x r x (1 - share)
Cash out before first return: hire = lag x C, vendor = 0
12-month total: hire = (12 - lag) x D x r - 12 x C
                vendor = (12 - lag) x D x r x (1 - share)
Walk away in month 3: hire = max(0, 3 + notice - lag) x D x r - (3 + notice) x C
                      vendor = max(0, 3 - lag) x D x r x (1 - share) - exit fee if lock-in > 3
Crossover rate        = C / (share x D)
Hire 12-month break rate = 12 x C / ((12 - lag) x D)
Letters per month     = D / average billed per row
Drafting cost         = letters x minutes / 60 x coder rate (+ tool cost on the shortcut)
Backlog               = D x months run; still appealable = D x min(months, window / 30)
12-month write-off    = 12 x D x (1 - recovered today %)

This is arithmetic on your figures. It is not legal, coding, financial, or investment advice. Notice periods, appeal windows, and contract terms depend on local rules and your contracts.
