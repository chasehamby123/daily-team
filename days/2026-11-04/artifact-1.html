Change the case settings

Where a machine reads the return

A machine can read the tax return and draft the nine numbers in about two minutes. A named analyst then checks each one. Who pays for this review depends on the lender's terms. Ask.

Who does what

The machine: reads the return, drafts the nine numbers, marks each one Draft.

A person still reviews: the analyst checks each number against the return and signs with their name. Your accountant confirms it is the return that was filed. You read the card and tick each number into your folder.

Change the review costs

Flat fee, or a share of the sale

A loan that runs for years can be a deal the lender shares in. The usual path is a flat fee at signing. The shortcut is a smaller fee plus a share of the price if you sell during the loan. Same inputs, both paths, three cases.

Change the fee terms

How the numbers are worked out

Interest a year = loan x rate All payments a year = interest a year + other loan payments a year Coverage = cash cleared after wages / all payments a year Building after cut = appraised value x (1 - forced-sale cut) Room left = building after cut - (loan + already owed) Plan holds when coverage >= break line AND room left >= 0 Push before it breaks: Cash can fall by = 1 - break line x (loan x bad rate + other) / cash Rate can reach = (bad-case cash / break line - other) / loan Cut can reach = 1 - (loan + already owed) / appraised value Safer loan size = the smaller of (bad-case cash / break line - other) / bad rate appraised value x (1 - bad cut) - already owed Flat fee path = loan x flat fee Share path = loan x small fee + sale price x share, if you sell within the loan term Machine review = first pass + cost of each blank (a machine cannot read a missing number)

Interest is counted as interest only. Many loans also repay principal each year, which lowers coverage. Enter the payments your lender quotes.

This sheet does not give legal, tax, or investment advice. Rates, fees, appraisal rules, and forced-sale cuts depend on the lender and on local rules. Enter the figures that apply to you. The dollar cost of each blank is an estimate drawn from a $60,000 first-pass review budget.
