With the tool and without it, per month

Average monthly cost over the first 12 months. Includes bookings still lost.

Steps a person still does

  • Every clinical question goes to a staff member. The tool books, moves and takes messages. It gives no clinical advice.
  • A staff member returns clinical calls within 15 minutes.
  • The practice manager reads the call summaries each morning and corrects any wrong booking.
  • The practice manager checks the per-booking bill against the appointment book each month.

The formula

weeks per month = 52 / 12 = 4.33 missed calls M = Missed calls last week x case multiplier hang-up share h = share who hang up on a recorded voice (bad 20%, base 10%, good 5%) booking rate b, booking value v, months T Change nothing = M x b x 4.33 x v x T Bookings still lost with the tool = M x h x b x 4.33 x v x T Cover, flat fee = tool fee x T + bookings still lost Cover, per booking = fee per booking x M x (1 - h) x b x 4.33 x T + bookings still lost Hire = salary x (1 + on-costs) / 12 x T + M x b x 4.33 x v x T - M x cover x b x 4.33 x v x (T - ramp weeks / 4.33, not below 0) Bookings lost since this started = Missed calls last week x months x 4.33 x b Desk time back (up to) = M x (1 - h) x minutes per call / 60 hours a week

"Workload" here means calls per week. It does not mean hours. "Looked after" means answered within 3 rings, and clinical calls returned by staff within 15 minutes.
